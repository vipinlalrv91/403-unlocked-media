Auto-Posting System Guide

403 UNLOCKED · The Stoic Bull · Kadha Petti — YouTube + Instagram automation
Status as of 26 November 2026 · Repository: vipinlalrv91/403-unlocked-media
In one line: every morning a scheduled Claude session writes, fact-checks and renders 2 videos per channel, saves them to GitHub, and queues them; a GitHub Actions publisher posts each one to YouTube and Instagram at its slot time, with a custom thumbnail.

   │  publish/run_outbox.py  → for every outbox item whose publish_at has passed:
   │     • Instagram Graph API → Reel + cover   (publish/ig_publish.py)
   │     • YouTube Data API    → Short + thumbnail (publish/yt_upload.py)
   │  moves the item to posted/ with the links (or keeps it queued if YouTube quota is full)
   ▼
 Slot-time "kick" tasks (10:03, 14:03, 16:03, 17:03, 18:03, 19:33 IST)
   └─ publish/kick.sh touches due items and pushes, so posting happens on time
      (GitHub's 30-minute schedule alone is unreliable), then reports the links.

5. Tokens: how to create or renew

5.1 Instagram (never-expiring Page token), per account

  1. Open Meta Graph API Explorer, choose the app, add permissions: instagram_basic, instagram_content_publish, pages_show_list, pages_read_engagement, business_management.
  2. Generate Access Token (log in yourself, click Allow).
  3. Open the Access Token Debugger → Extend Access Token (long-lived user token).
  4. Back in Explorer, paste the long-lived token and call me/accounts; copy the access_token of the Page linked to the Instagram account.
  5. Check it in the Debugger: Expires: Never. If it shows a date, step 3 was skipped.
  6. Save it as IG_TOKEN_<CH> in GitHub Secrets. Then say "token updated" and pending posts are retried.
A Facebook password change or security checkpoint invalidates all page tokens; redo the steps above for every account.

5.2 YouTube refresh token, per channel

  1. Open OAuth 2.0 Playground → gear icon → tick Use your own OAuth credentials → paste the client ID + secret.
  2. Scopes: https://www.googleapis.com/auth/youtube.upload and https://www.googleapis.com/auth/youtube.force-ssl.
  3. Authorize APIs → choose the correct Google account and the correct channel → Allow.
  4. Exchange authorization code for tokens → copy the refresh token carefully (whole string).
  5. Save to the matching GitHub secret (remember the STOIC/KADHA swap). Verify with the verify workflow.
Custom thumbnails need a phone-verified YouTube channel (youtube.com/verify).

7. The daily run, step by step

  1. Credits: ElevenLabs balance; push notification if below 12,000 characters.
  2. 403 UNLOCKED (2): next topics from topics/queue.md (refilled when fewer than 3 remain) → fact-check with official sources → episodes/<slug>.json → python3 pipeline/make_short.py episodes/<slug>.json → QC frames → copy to videos/approved/<date>_<slug>.mp4 + thumb → push → outbox at 10:00 / 16:00.
  3. Kadha Petti (2): next 2 unchecked episodes in channels/kadha/ramayanam.md → JSON with story scenes, character lines, moves (enter/walk/kneel/bow) → new characters drawn with art/generate.py + face points + voice → render → channels/kadha/videos/ramayanam-NN.mp4 → outbox at 17:00 / 19:30.
  4. Stoic Bull (2): next 2 days in channels/stocks/curriculum.md → SEBI-safe JSON → python3 channels/stocks/export.py … → outbox at 14:00 / 18:00.
  5. Mark topics done, log to runs/log.csv, push, and send a summary with yesterday's YouTube + Instagram links.

8. Weekly long Ramayanam video + Google Flow

  • Full-screen 16:9 YouTube video, uploaded manually by the owner in YouTube Studio (title, description with chapters, tags, thumbnail are supplied in channels/kadha/long/part-N-…-upload.txt).
  • Fresh production from Part 1 (26 Nov 2026): our full-screen episodes (pipeline/make_wide.py) joined as one story (no per-episode intros/teasers), with Google Flow hero shots placed at the matching moments.
  • Settings when uploading: Made for kids = Yes; Altered or synthetic content = Yes (Flow scenes are AI).

Google Flow workflow (manual, owner's Pro credits)

  1. I send a prompts file (e.g. channels/kadha/flow/part1/PART1_FLOW_PROMPTS.txt) and a zip of our character + background images.
  2. In Flow: New project → Ingredients to Video → upload the listed images → paste STYLE LINE + shot prompt → 16:9 → Veo Fast → download.
  3. Name files P<part>-S<shot>.mp4, put them in a Google Drive folder, share "Anyone with the link", send the link.
  4. I download them, check faces/style, blur the Flow sparkle watermark, place them in the episodes, add our voice + music + captions, and send the finished video, thumbnail and upload text.
Tip: choose 8-second clips in Flow if available (Part 1 clips were 4 s). Describe each character's skin and clothes in the prompt; Flow sometimes swaps costumes.

10. Manual operations

  • Post a video now: say "post now" → an outbox item with publish_at = now is pushed and kicked; links come back in a few minutes.
  • Save only: "no need to post, just add in git" → video saved in videos/approved/, no outbox item.
  • Check tokens: "check tokens" → verify workflow → result for all 3 channels.
  • Re-post pending after a token fix: "token updated, post pending" → stuck outbox items are re-kicked.
  • Reference reel: send an Instagram link → I download it, study the structure, and make our own original version.

12. Safety rules and owner decisions

  • Passwords, keys and tokens are never pasted in chat; they go only into GitHub Secrets or the environment's Network secrets. The owner clicks every Google/Facebook consent screen personally.
  • No paid service is started without the owner's decision (ManyMotions trial declined; Azure skipped).
  • Stoic Bull: education only; no stock names as recommendations; hypothetical numbers only; SEBI disclaimer always.
  • 403: verified facts with sources in every episode; "path may vary by phone"; no fake app screens; no people in photos.
  • Kadha: gentle, non-graphic retelling for children (Valmiki / Adhyatma Ramayanam, public domain); same character faces throughout.
  • Movie clips / film actors' faces risk copyright claims; AI-generated realistic scenes are labelled as altered/synthetic on YouTube.
